# 掐指連總經 Suanomics

讀者：維護者、貢獻者、在本 repo 工作的 AI coding agent
型別：入口

每個台股交易日開盤前，自動產出一份總經報告：前一晚世界上發生了什麼、透過什麼機制牽動哪些台股標的、方向為何，每條連動鏈附引用來源。網站：`suanomics.everbegin.net`。

`rewrite` branch 是從空樹重建的版本；v0 的程式碼與文件在 `main`（tag `v0-legacy`）。
