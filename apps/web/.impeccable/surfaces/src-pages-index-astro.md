# 讀者面：每日報告（首頁、單日頁、歷史、新聞頁）

Mode: Read。手機首屏為主，桌機要成立。

讀者：不看盤、財經知識不深的公開讀者，開盤前用手機快速掃。卡點：找不到重點、看不出牽動哪些台股、術語看不懂（術語另開 issue，版面留位置）。

## Direction contract

THESIS: 賽博半仙是補教名師，每天發一張「開盤前重點講義」：先畫重點（主軸＋牽動產業），再給分節詳解。拒絕財經新聞站的文章頁排法（麵包屑、標籤、一大片內文）。

OWN-WORLD: 影印講義紙的冷白底、墨黑字；藍筆（#1e4fd8）畫框與連結，紅筆（#d7262e）寫每節一句話結論，黃色螢光筆只劃本日主軸。講義抬頭（科目、回次、日期、名師）粗底線；「本日必考重點」是藍框加框上標籤；方向照台股紅漲綠跌，另配形狀記號與文字。

STORY: 讀者一打開就知道今天的主軸、哪五個產業被牽動、往哪個方向；想深讀就往下看詳解與出處，每句都能點回來源。

FIRST VIEWPORT: 手機：講義抬頭（品牌＋slogan 左、開盤前重點講義＋日期右）→ 回次／閱讀時間／來源數一列 → 標題 → 藍框「本日必考重點」：主軸一句、五個產業逐列（序號、產業、方向）。桌機：同一欄 68ch，右側固定「本講義目錄」。
